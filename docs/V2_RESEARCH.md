# The Grey Project V2 — Design Research

Principles extracted from industry leaders (patterns only — not visual copies).

## Duolingo / Brilliant

- Micro-lessons with immediate feedback loops
- Progress visible in under 3 seconds
- Streaks and identity reinforcement
- "One more step" momentum over chapter walls

## Linear / Stripe / Figma

- Calm density, strong hierarchy, fast surfaces
- Actions anchored; no mystery navigation
- Premium restraint — whitespace as confidence

## Apple Education / DeepLearning.AI

- Concept before notation
- Visual-first explanations, then formalism
- Checkpoints that prove understanding, not recall

## Notion / Observable / HuggingFace

- Explorable sandboxes beat passive video
- Users learn by manipulating parameters
- Community and artifacts deferred until core loop works

## Replit

- Try before account
- Builder identity — "I made it work"

## V2 Thesis

| Avoid | Build |
|-------|--------|
| Coursera-length units | 5–12 min interactive arcs |
| Text walls | Hook → Visual → Play → Checkpoint |
| Login-first | Land → Try → Understand → Signup |
| Theory-first | Intuition-first, math second |

## Success loop

**LAND → TRY → UNDERSTAND → SIGNUP → LEARN → RETURN → MASTER**
