# The Core Mental Model

At its core, a neural network is:

```txt
A giant mathematical function approximator.
```

The goal is simple:

```txt
Input → Learn Patterns → Predict Output
```

Example:

| Input | Output |
| --- | --- |
| Image pixels | Cat / Dog |
| Audio waveform | Spoken words |
| Previous tokens | Next token |
| User history | Recommendation |
| Sensor data | Fraud probability |

Neural networks learn statistical structure automatically from data.

---

# Biological Inspiration

Neural networks were loosely inspired by the human brain.

Biological neurons:

- receive signals
- process information
- activate outputs

Artificial neurons follow a similar abstraction.

Example:

```txt
Inputs → Weighted Sum → Activation → Output
```

But modern neural networks are not realistic brain simulations.

They are optimization systems built using mathematics and linear algebra.

---

# The Artificial Neuron

The simplest building block is the neuron.

A neuron receives inputs:

```txt
x1, x2, x3...
```

Each input has a weight:

```txt
w1, w2, w3...
```

The neuron computes:

```txt
z = w1x1 + w2x2 + w3x3 + b
```

Then applies an activation function.

Example:

```txt
output = activation(z)
```

This tiny operation powers the modern AI revolution.

---

## Why We Need Activation Functions

Without activations:

```txt
Neural networks collapse into linear systems.
```

Activation functions introduce:

- nonlinearity
- complexity
- expressiveness

Common activations:

| Activation | Purpose |
| --- | --- |
| ReLU | modern deep learning default |
| Sigmoid | probability outputs |
| Tanh | normalized activations |
| Softmax | probability distributions |

Nonlinearity allows networks to model complex real-world patterns.

# Layers and Hierarchies

Neural networks stack neurons into layers.

Typical structure:

```txt
Input Layer
    ↓
Hidden Layers
    ↓
Output Layer
```

Each layer learns progressively more abstract representations.

Example in vision systems:

```txt
Pixels
→ edges
→ textures
→ shapes
→ objects
→ concepts
```

This hierarchical representation learning is one of the deepest ideas in AI.

---

# Why Deep Learning Is Called “Deep”

“Deep” simply means:

```txt
Many layers.
```

Early ML systems were shallow.

Modern systems may contain:

- dozens of layers
- hundreds of layers
- thousands of layers

Large Language Models contain billions of parameters across extremely deep architectures.

Depth increases representational power.

# Tensors: The Language of Deep Learning

Deep learning systems operate on tensors.

A tensor is simply:

```txt
A multidimensional array.
```

Examples:

| Tensor Type | Example |
| --- | --- |
| Scalar | single number |
| Vector | 1D array |
| Matrix | 2D array |
| Tensor | higher-dimensional structure |

Examples in AI:

| Data | Tensor Shape |
| --- | --- |
| Image | height × width × channels |
| Video | frames × height × width |
| Audio | time × frequency |
| Text embeddings | token × embedding dimension |

Modern AI is fundamentally tensor computation.

# Forward Propagation

During prediction:

1. Inputs enter the network
2. Activations flow layer by layer
3. Final predictions emerge

This process is called:

```txt
Forward Propagation
```

Example:

```txt
Image → Layers → Prediction
```

The network transforms raw inputs into increasingly meaningful representations.

---

# The Learning Problem

Initially, network weights are random.

Predictions are terrible.

The network must learn:

```txt
Which weights produce good predictions?
```

This is where optimization enters.

---

# Loss Functions

Neural networks measure mistakes using loss functions.

Examples:

| Problem | Common Loss |
| --- | --- |
| Classification | Cross Entropy |
| Regression | Mean Squared Error |
| Language Models | Token Cross Entropy |

The loss quantifies:

```txt
How wrong was the prediction?
```

Training becomes:

```txt
Minimize Loss
```

---

# Backpropagation

Backpropagation is one of the most important algorithms in AI history.

It allows networks to learn efficiently.

The process:

1. Make prediction
2. Measure error
3. Compute gradients
4. Update weights
5. Improve predictions

This loop repeats millions or billions of times.

---

## Intuition Behind Backpropagation

Backpropagation answers:

> Which weights caused the mistake?

The algorithm computes gradients showing:

```txt
How much each parameter contributed to the error.
```

Then optimization algorithms update parameters.

---

# Gradient Descent

The most common optimization strategy is:

```txt
Gradient Descent
```

Imagine standing on a mountain in fog.

Your goal:

```txt
Find the lowest point.
```

Gradients indicate:

```txt
Which direction decreases loss fastest.
```

The network repeatedly moves downhill.

This process powers modern AI learning.

# Overfitting

Neural networks are extremely powerful.

Too powerful sometimes.

They can memorize training data instead of learning general patterns.

This problem is called:

```txt
Overfitting
```

Example:

```txt
Perfect training accuracy
Poor real-world performance
```

This is dangerous.

---

# Techniques to Reduce Overfitting

| Technique | Purpose |
| --- | --- |
| Dropout | random regularization |
| Data augmentation | more diverse examples |
| Early stopping | avoid memorization |
| Weight decay | penalize complexity |

Generalization matters more than memorization.

- stable gradient updates
